# 流程操作与工具调用

在进入计划、实现、调试、恢复、验证或收尾工作时读取本规程。工程判断遵循同包的 [工程规程](engineering.md)；按项目现有语言、目录、工具和已作决定执行。

## 先判断可用能力

**当前版本没有 tao CLI。** 下表列出后续工具接入的调用时机；当前按“实际动作”执行，并说明自动检查尚未提供。不要执行不存在的命令，不寻找或安装 PATH 中碰巧同名的程序，不将人工查看冒充自动校验。

后续包实际提供 `scripts/tao.py` 或项目明确指定 tao-dev 入口后，才通过该受信任路径调用 `doctor --format json`。确认结果中的工具标识为 `tao-dev`、协议版本可理解且 `capabilities` 包含所需命令。表中的 `tao` 是该入口的简写，不要求全局安装。入口或能力缺失时报告具体缺口，使用已有项目工具继续能完成的部分；所需保证缺失时保留未验证。

## 按任务阶段执行

| 时机 | 实际动作与最小产物 | 对应工具接入点，能力存在后才调用 |
|---|---|---|
| 首次进入项目或工具／配置变化 | 确定项目根、范围、约定与现有检查命令；区分可用和缺失能力 | `tao doctor` |
| 开始非微小变更 | 复用已有规格与计划；写明目标、边界、验收和未决问题，不重复询问已明确的内容 | 需要新计划且支持模板时 `tao start`；创建正式条目时 `tao id new`；无工具时按已采用的项目格式记录 |
| 澄清、设计、规划 | 先查实现与调用方，独立分析用户方案的收益与代价，补足会改变判断的场景；确定最小方案、任务依赖、修改范围与验证方法 | 编辑文档后 `tao check`；查已有条目用 `tao resolve`。不存在“命令已替我完成设计”的结果 |
| 实现或重构 | 按任务完成一个可验证结果，保持不相关工作；代码与受影响的规格／说明同步 | 文档变更后 `tao check`，行为变更后运行项目检查；支持证据记录时使用 `tao verify` |
| 调试 | 复现或保留现场，提出可证伪假设，以最小实验区分原因；修复后重跑原场景与回归 | 按已配置检查执行 `tao verify` 或项目原生命令；失败结果不能改写成成功 |
| 评审 | 读取 [审查规程](review.md)，按风险对相关文件及代码进行独立、对抗式审查；加强审查优先跨供应商，意见含约束、场景、证据、后果与解除条件 | `tao check` 核对结构，`tao status` 查证据时效；语义评审仍需实际进行，不虚构 `tao review` 或跨模型执行结果 |
| 恢复会话 | 阅读当前目标、已作决定、阻碍与下一步，核实文件和证据是否仍一致，不仅信任交接摘要 | `tao status` 与必要的 `tao resolve`；不把恢复操作伪装成已实现的 `tao resume` |
| 中断或交接前 | 保存精简交接：目标、约束、决定、实际状态、证据入口、阻碍和下一步 | 支持时 `tao checkpoint` 保存 agent 提供的摘要；否则更新项目已有交接位置 |
| 收尾前 | 检查验收、当前证据、阻断与实际授权；向用户说明结果与剩余限制 | `tao check`、必要的 `tao verify`、`tao finish`；finish 只检查记录条件，不自动批准、提交或发布 |
| 删除正式条目或生成文档站点 | 处理引用与退役；出版时验证实际链接而非仅查看源文 | 分别使用支持的 `tao retire`、`tao docs build`；退役写入需明确应用，构建不附带部署 |

局部文案／格式修正无需创建一套变更档案；采用相称检查和交付说明即可。沿用已有文档契约，不因本 skill 的开发文档有某种结构就强制目标项目迁移。未定义的模板、状态或 ID 类型不得由 agent 假装工具已支持。

## 读懂结果并保持边界

工具退出 `0` 只证明相应确定性检查成功，`1` 表示存在不满足条件的结果，`2` 表示工具或配置故障、检查未完成。对项目原生命令以其实际退出码和输出为准，不能套用 tao 的退出码含义。逐项记录通过、失败、未执行、不适用和已过期；不能用复述规则、代码量或任务勾选代替行为证据。

验证前后受检输入若发生变化，重验受影响部分。使用文件内容指纹与必要环境描述，VCS 修订仅作补充，不要求使用 Git。`artifacts/` 中的临时报告默认不属于长期证据；需要长期引用时按项目约定归档摘要和必要原报告，记录校验和与保存期限。

斜杠命令只负责进入这些操作，hook 只提供经过实现和验证的辅助检查。未实现或被禁用时不能声称它们自动执行过。测试本 skill 时只在隔离项目或单次调用内启用，不安装到全局、不修改全局配置。
