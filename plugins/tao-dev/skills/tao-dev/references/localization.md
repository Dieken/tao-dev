# 翻译与多语言文档

翻译已有文档、生成派生语言视图或扩展模板语言时读取。新文档语言选择与诊断入口见 [文档规程](documents.md)。

## 稳定结构与显示文字

schema、章节／字段键、ID、关系、状态、规则号和模板变量保持英文／ASCII 协议形式；正文、标题、说明与标签可翻译，日期等机器字段仍遵循固定格式。ADR 标签可翻译，保留其显示结构约束。

模板共用结构，显示文字按 locale 选资源；已有简体中文和英文资源。新增语言沿用相同变量键集，整段消息允许重排变量，缺项报告回退或缺失。尚无内容质量规则的语言仍可检查结构，明确未检查的质量项。

## 权威源与派生视图

每个文档或条目有一个权威源语言，其他语言为派生视图，保留源版本／摘要与审校状态；源文变化后待复核。结构通过不自动认可译文。

同一语义对象保留 ID，译文不重新注册正式定义或新增批准状态；同版本同 locale 的重复定义仍报错。多权威语言项目先建立全局索引，不按语言独立编号。译文新增承诺时按需求变更处理。

## 诊断呈现

`--diagnostic-locale en|zh-Hans` 与 `[ui] locale` 独立于正文 --locale；优先显式参数、界面配置、源文档 locale。无可解析源或无翻译时回退英文，读取实际 message_locale。CLI 帮助、状态枚举及外部工具原始输出不属于已翻译诊断；翻译说明与原始证据分开。
