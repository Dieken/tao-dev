# 书籍导航、构建与稳定链接

组织书籍导航、构建 HTML 或维护分享链接时读取相关小节。文件归属与命名见 [文档组织](document-layout.md)。已有书籍的日常构建只需“构建与检查”；导航或链接发生变化时再读对应规则。

## 构建与检查

配置 documents.book_root 后执行 `tao docs build`。依赖缺失时按 [运行环境](runtime.md) 准备出版环境；构建本身不安装依赖。输出位于配置的 temporary 下的 book/，默认 tmp/tao/book/，以 JSON 输出 index 为实际首页。

检查生成入口、所改页面与构建诊断，再给出本地 HTML 链接。Sphinx 警告视为失败，构建失败保留上次书籍。HTML、日志和缓存按 [证据保存](evidence-retention.md) 管理。部署需要单独的明确授权；当前不提供 PDF 和跨版本站点重定向。

首次构建或清空输出后没有上一版基线，此时不能声称已检查删除。长期发布保留上一版本入口，已出版 ID 保留定义或退役记录。

## 阅读层级与导航

书籍按书、篇、章、内容页组织；篇按读者与职责，章按能力、子系统或操作主题。篇章不增加实体类型，目录页仍使用 DOC ID。

| 层级 | 默认入口 | 组织方式 |
|---|---|---|
| 书 | docs/index.md | 读者、阅读路线和已有分类 |
| 篇 | 各职责目录的 index.md | 多篇书籍的已有一级分类保留入口，即使只有一份正文 |
| 章 | 主题.md 或主题/index.md | 单页保留文件，多份独立维护的主题才建目录页 |
| 内容页 | 主题/具体内容.md | 采用相应 profile，实质内容只维护一处 |

只创建实际内容所需层级；只有一篇的小书可从书入口直接列章。默认阅读顺序为用户、运维、产品、工程、术语、交付记录，可按项目读者任务调整。运维正文采用 runbook，归入 operations。计划无出版附件时直接列入月份目录；有附件时由同名目录的 index.md 组织计划和附件，月份目录只挂该事项入口。

使用 [navigation 模板](../assets/templates/navigation.md)：overview 写读者与范围，contents 恰有一个顶层 toctree，使用 `:maxdepth: 2` 和 `:titlesonly:`。条目按阅读顺序逐行写相对当前目录页的 Markdown 源路径，包含 .md；不写外链、片段、glob、self 或额外显示标题。显示标题取目标文档。

每页在主目录中只有一处位置，全部从书入口可达、无环、无重复目标；其他主题用普通链接或 ID 引用。草稿、模板和未出版资料显式排除，不用全局 orphan 隐藏漏挂。父子关系和顺序只维护在 toctree，不另存 part／chapter／parent／order 或平行 SUMMARY 清单。

目录、文件名和标题不手写阅读序号。构建器按导航生成编号；正文、左侧导航和页内目录共用编号，navigation 的固定导读和目录标题不编号。顺序变化只改目录，移动文件时更新路径与普通链接，保持 ID。导航调整后检查层级、前后页、可达性与编号。

## 稳定链接

正文正式引用用 `{need}` 加完整 ID；构建后显示目标类型与标题。关系和任务引用由工具生成可点击入口，不手工复制关联表。自动标题 slug 仅用于普通小标题，不作为正式永久链接。

| 目标 | 锚点 | 固定入口 |
|---|---|---|
| 文档／条目 | 完整 ID | `refs/<ID>.html#<ID>` |
| 二级章节 | `<DOC-ID>--<section-key>` | `refs/<DOC-ID>.html#<DOC-ID>--<section-key>` |

分享与复制链接使用固定入口；更细内容需要独立分享时使用正式条目或独立文档的固定章节。文件移动、标题和显示编号变化不改变这些标识，历史版本链接保留版本路径。域名或书根变化需要站点迁移重定向。

## 跨文档章节迁移

移动已分享章节到另一 DOC 时配置旧章节到当前章节的映射，并执行文档检查与构建：

```toml
[documents.section_redirects]
"<旧 DOC-ID>--<旧章节键>" = "<当前 DOC-ID>--<当前章节键>"
```

旧 DOC 须仍有源定义或退役记录，目标须为当前文档的实际二级章节。映射直接指向最终位置，不允许自指、环或多跳；再次迁移时更新已有映射。原文按格式保留简短入口，或退役已不需要的文档，不复制正文。

构建后访问本次受影响的旧固定入口，核对目标与复制链接。映射保护书籍固定入口，不恢复已删除的 Markdown 路径、托管平台自动锚点或旧域名。仍作为重定向目标的文档不能退役。
