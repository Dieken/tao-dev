# tao-dev · 项目文档与知识管理

用结构化文档保存可追溯的项目知识，用持久计划与任务保存跨会话、跨客户端的项目进度。tao 管理文档与项目结果，不编排智能体的开发执行、代码审查或会话阶段。

| 记录、读取、核对和回写项目进度与结果 | [持久计划](references/planning.md) |
| 审查文档的语义、依据与一致性 | [文档审查](references/review.md) |
| 校验源文档 | [文档校验](references/tools.md#文档校验) |
| 出版、翻译或退役文档 | [出版](references/publication.md)、[本地化](references/localization.md)、[退役](references/retirement.md) |
| CLI、可选项目配置与依赖准备 | [工具入口](references/tools.md)、[运行环境](references/runtime.md) |
