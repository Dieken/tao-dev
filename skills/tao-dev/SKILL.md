# tao-dev · 项目文档与知识管理

用结构化文档保存可追溯的项目知识，用持久 plan/tasks 保存跨会话、跨客户端的项目进度。tao 管理文档与结果知识，不编排 agent 的开发执行、代码审查或会话阶段。
