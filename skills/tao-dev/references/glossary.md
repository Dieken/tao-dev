# tao 术语

涉及 tao 概念、约定名称或用词冲突时查询对应条目。使用方项目的领域术语由该项目术语表维护；精确语法见 [文档规程](documents.md)。

## 易混淆概念

| 用语 | tao 约定 |
|---|---|
| 标识符 | 对象的固定标识；不用“身份”或“标志”指代 ID |
| 对象同一性 | 修改前后仍是同一对象；与认证身份区分 |
| 规格／设计／计划 | 分别维护承诺与验收、实现选择与理由、一次事项的可验证结果与进度；不是强制先后阶段 |
| 条目 | 可独立引用的需求、用例、决策或任务；普通段落不是条目 |
| 篇／章 | 按读者职责／主题组织阅读，不增加实体类型 |
| 验证／验收 | 检查约束和行为／判断是否满足约定交付；工具检查不自动作出验收决定 |
| 产物／证据 | 文件是产物；明确记录输入、条件和结果且可复核的记录才是证据 |
| 项目事项（CHG）／变更 | 一次有独立目标、由计划跟踪的项目工作；「变更」也可表示一般意义的修改 |
| 检查输出 | 项目工具生成的原始结果与日志；不等于审查结论，保存规则见 [结果保存](planning.md#结果保存) |
| 结构规范（schema）／文档格式（profile） | 前者约定结构与关系；后者规定具体文档类型采用的字段、章节与条目。指字段时保留 `schema` |
| 技能（skill）／智能体（agent） | 前者是供客户端加载的指令与配套资源，后者是执行任务的程序主体；具体目录、命令和客户端名称保留原文 |
| 退役／弃用 | 退出有效集合／不建议继续使用；弃用不自动移除定义 |
| 项目任务／客户端任务 | 计划与任务文档中跨会话共享的可验证结果／智能体的临时执行步骤；进度归属见 [持久计划](planning.md) |

## 项目受控术语

只收录跨文档易混淆或反复误用的词，局部术语留在所属规格或设计。项目术语表的 `terms` 节用 `{term} 首选名称` 围栏，正文为定义；可选 `:english:`、`:code:`、`:scope:` 和 `:avoid:`（JSON 字符串数组）。不新增 TERM ID；定义只维护一处，其他位置链接。校验器检查条目结构、同范围重名与自相矛盾的禁用名称；语义误用由审查判断，不全文禁止“身份”等多义词或误报反例。

## ID 类型

| 前缀 | 对象 |
|---|---|
| DOC | 文档本身 |
| REQ | 可独立验收的需求 |
| UC | 验收场景或性质，通过 `verifies` 关联 REQ |
| ADR | 技术决定 |
| TASK | 可验证工作单元，必须说明检查办法（`verify`）；依赖、关联和证据链接（`evidence`）可选 |
| CHG | 由计划定义的项目事项标识，与计划 DOC 不同；不要求先登记事项才能维护规格或设计 |

完整格式由注册表定义；文件及其内条目各有独立 ID。机器字段保持原名，显示标签使用项目语言。
