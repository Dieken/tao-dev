# 文档语义审查

审查文档能否准确表达目标、承诺、方案、操作或项目进度，而不只检查模板字段。结构校验不能代替语义判断；文档审查也不认证实现或交付。

## 范围与依据

确定实际受检文档、版本、原始目标、有效约束及关联资料。实现、调用方、测试和用户观察可作为核对来源，但本规程不编排代码审查。资料不足、来源过时或没有可还原快照时，明确结论的限制，不能补造依据。

局部低风险内容可自查；跨文档契约或高后果决定按风险和用户授权选择独立审查。独立审查者先看原始材料与正式决定，不先看作者自评或其他意见。角色名不同不证明模型独立；能力不可用就说明未执行，不发起未经授权的模型会话。

## 检查语义

- 规格：目标与范围是否一致，承诺是否独立、可观察且有真实来源，验收是否充分且没有悄悄增加或削弱需求。
- 设计与决定：假设是否有依据，边界、接口、数据、不变量、失败与恢复是否明确，取舍及维护成本是否合理；避免无需求支撑的复杂度。详见 [正文写法](document-content.md)。
- 计划与任务：是否覆盖目标、描述可验证结果、表达真实依赖，是否只有一份任务集；记录的完成、验证与审查是否有对应事实，未知与限制是否明确。详见 [持久计划](planning.md)。
- 指南与 runbook：读者、前提、步骤、权限、副作用、失败处理和验证办法是否足够且与当前行为一致。
- 共同内容：术语、ID、关系和导航是否一致；是否有过时、矛盾、重复或失去权威来源的内容。结构通过不证明外部资料真实、链接内容正确或操作可行。

每项发现说明定位、违反的契约、条件、依据、影响及最小修正或求证方法；区分真实缺陷、未证实风险和非阻断建议，允许无发现。逐项以原始目标、有效决定及可核实事实裁决，记录采用、不采用或未解决的理由。模型一致不是证据，不能为了符合实现缺陷而机械降低文档承诺。修改后按影响复核，不为凑轮数反复审查。

## 结论归属

报告实际范围、结论和未核实内容，不以任务全勾选推断已审查。不创建审查批次、调度记录、回执或长期报告文档。详细输出留对话、临时目录或 CI；已有计划仅保存当前结论与限制，长期要求与决定直接更新权威文档。审查是文档管理活动，不是单独的受管理文档类型。
