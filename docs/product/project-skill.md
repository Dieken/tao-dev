# 项目级文档驱动技能

<!-- tao:section scope -->
## 目标与边界

tao-dev 是项目级文档与知识管理技能（skill），以语义契约、持久项目计划和确定性辅助工具支持协作。范围包括文档创建、修订、语义审查、关联、查询、退役与出版，不包括通用开发执行编排。智能体自行管理执行，将实际成果回写项目文档。安装及项目操作限定在明确授权的项目内，不修改其他项目、个人配置或全局安装。

<!-- tao:section terms -->
## 术语

技能包由 [SKILL.md](../../skills/tao-dev/SKILL.md)、按需参考、模板及确定性辅助脚本组成。持久计划与任务文档是跨会话、跨客户端的权威项目进度；客户端任务列表只是临时执行步骤，不构成第二份进度来源。任务勾选、验证、审查与交付分别表达，未知不得推断通过。

<!-- tao:section requirements -->
## 需求

```{req} 项目级纯技能包
:id: REQ_20261108_QYFN37DN0SHS8376
:status: proposed

分发完整技能包，由使用者复制到项目级发现目录或选择通用技能管理工具；tao 不提供安装生命周期、所有权记录或客户端配置管理。复制不要求 Python，不隐式准备依赖。

<!-- tao:field acceptance -->
**验收：** 隔离项目内复制完整包、从副本运行辅助命令并移除副本；确认项目文档、项目外客户端配置及用户目录不变。实际客户端发现另行验证能在项目内发现技能、在项目外无法发现，不以复制结果代替。

<!-- tao:field source -->
**来源：** 用户的项目级技能与简化协作要求。
```

```{req} 文档生命周期与语义管理
:id: REQ_20261108_6FN7VP6CB598Y1DV
:status: proposed

按实际知识需要创建、修订、审查、关联、查询、退役与出版文档。规格约束行为与验收，设计说明结构、接口与失败边界，ADR 记录长期取舍。复用已有权威材料，不为每次修改强制生成规格、设计和计划，不提供通用实现、代码审查或恢复动作来编排开发。

<!-- tao:field acceptance -->
**验收：** 小改动只更新相关材料；语义审查能识别含糊验收、矛盾设计和遗漏边界，不以格式通过代替内容正确。CLI 的 `new` 命令只生成计划骨架，查询不返回流程下一步建议。

<!-- tao:field source -->
**来源：** 用户的项目级技能与简化协作要求。
```

```{req} 计划是进度唯一来源
:id: REQ_20261108_EQQAQ6NE9CBMT5SP
:status: proposed

跨会话、多人协作或需要持续跟踪的工作使用持久计划。任务默认内联在计划中，必要时由 `tasks_doc` 唯一关联一份附件；任务表达可验证成果与依赖，而非客户端临时步骤。智能体核对真实产物后写回任务、阻碍与实际验证摘要，保持唯一项目进度。任务完成不能自动证明测试、审查或交付通过。

<!-- tao:field acceptance -->
**验收：** 只有计划与任务文档的项目可以只读查询；更换会话或客户端后可从计划与实际文件定位剩余成果，临时任务列表丢失不影响项目进度。`status` 固定返回计数、待办和源文件位置，不复制验证正文、不生成审查结论；全部勾选也不能据此声称审查通过，缺少审查依据由智能体明确说明未知。

<!-- tao:field source -->
**来源：** 用户的项目级技能与简化协作要求。
```

```{req} 结构化知识与文档书籍
:id: REQ_20261108_C06F8GD5AWHTY6AD
:status: proposed

文档采用稳定唯一 ID、正向引用和文档书籍导航；校验基本结构、必要语义章节、唯一 ID、引用和导航完整性，允许章节重排及与当前文档无关的可选章节缺省。语义审查另行核对要求、设计依据、任务成果与实际知识的一致性，不把机器格式校验称为语义证明。

<!-- tao:field acceptance -->
**验收：** 核心文档可校验和构建；重排可选章节不失败，重复 ID、悬空引用及导航环失败。元数据只保留独立知识或必要进度关系，不维护通用编辑日期、无范围的覆盖粗分类或设计对单次变更的归属；未知字段明确拒绝。`verify` 固定给出计数与诊断。

<!-- tao:field source -->
**来源：** 用户的项目级技能与简化协作要求。
```

```{req} 当前知识与变更记录分离
:id: REQ_20261108_M77FHDMQ112NKMDP
:status: proposed

审查与证据的详细输出留临时目录或 CI，不作为长期受管理文档，不提供对应结构规范或正式证据 ID。计划保留当前结果摘要，完成后作为变更记录保存；当前有效要求、设计与长期取舍回到规格、设计或 ADR，不使旧计划成为现行知识的唯一入口。临时摘要不是恢复前置条件，也不形成独立进度源。

<!-- tao:field acceptance -->
**验收：** 完成计划可追溯当时成果与验证限制，后续变化更新权威知识而不改写旧结果；`status` 不运行测试或写文件；生成的文档不收录临时执行记录，`review`/`evidence` 结构规范与正式证据 ID 均拒绝。文档语义审查和任务的普通来源链接仍可使用。

<!-- tao:field source -->
**来源：** 用户的项目级技能与简化协作要求。
```

```{req} 当前接口与分发一致
:id: REQ_20261108_2KN2TMG33K5M47TV
:status: proposed

结构规范、模板、校验器、文档、测试和打包共同表达当前技能契约；分发资源及每个公开接口都有明确的当前使用方，项目操作限定在授权范围。

<!-- tao:field acceptance -->
**验收：** 运行当前命令、项目复制冒烟检查、文档验证、文档书籍构建和回归；核对接口、资源及文档一致，用户目录与项目外配置保持不变。

<!-- tao:field source -->
**来源：** 用户的项目级技能与简化协作要求。
```



<!-- tao:section cases -->
## 场景

```{uc} 项目隔离
:id: UC_20261108_N9H9WRFKXP27AJ2W
:status: proposed
:verifies: REQ_20261108_QYFN37DN0SHS8376

<!-- tao:field given -->
**给定：** 两个临时项目与隔离用户目录。

<!-- tao:field when -->
**当：** 只向第一个项目复制完整技能包、运行辅助工具并移除副本。

<!-- tao:field then -->
**则：** 第二个项目和用户配置保持不变，不属于该技能包的文件不被删除。
```

```{uc} 跨会话与客户端保留项目进度
:id: UC_20261108_7S9B1Y91CBPVRZXH
:status: proposed
:verifies: REQ_20261108_EQQAQ6NE9CBMT5SP

<!-- tao:field given -->
**给定：** 已有持久计划及其唯一任务集，客户端临时任务列表已丢失。

<!-- tao:field when -->
**当：** 在另一会话或客户端用 `status` 查询，并由智能体核对实际产物。

<!-- tao:field then -->
**则：** 可定位未完成成果与阻碍；智能体根据事实回写同一任务集和验证摘要，不另建进度源；没有审查记录时，审查结果保持未知。
```

```{uc} 文档结构与导航校验
:id: UC_20261108_V5DFY36HGWZVS6P2
:status: proposed
:verifies: REQ_20261108_C06F8GD5AWHTY6AD

<!-- tao:field given -->
**给定：** 具有现有结构与唯一 ID 的文档书籍。

<!-- tao:field when -->
**当：** 按当前模板编写文档，重排可选章节并执行校验与构建。

<!-- tao:field then -->
**则：** 核心引用仍可解析，可选章节重排不影响校验，重复 ID 和导航错误仍被检测。
```



<!-- tao:section questions -->
## 未决问题

无产品边界待决。客户端发现项目技能的能力须如实验证；无法确认项目隔离时报告未验证，不回退全局配置。
