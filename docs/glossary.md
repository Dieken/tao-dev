# 术语与缩写

通用术语已作为运行材料随 skill 分发；本文保留本项目的语境说明和阅读入口，使用方的领域术语仍由其项目自己维护。

<!-- tao:section terms -->
## 一、概念与中文用语

标识符、对象同一性、规格、设计、证据与审查等概念统一见 [随包术语表](../plugins/tao-dev/skills/tao-dev/references/glossary.md)。本项目的“自举”指用本仓库内的 skill 源码及其规则开发 tao-dev；无需将产品全局安装。

<!-- tao:section prefixes -->
## 二、ID 类型前缀

DOC、REQ、UC、ADR、TASK、CHG、EVD 的英文全称、用途及区别在 [随包术语表](../plugins/tao-dev/skills/tao-dev/references/glossary.md) 定义；精确语法在随包文档规程与格式注册表定义，不在这里重复。

<!-- tao:section abbreviations -->
## 三、其他缩写

SDD、VCS、CLI、AST、i18n 等缩写统一见 [随包术语表](../plugins/tao-dev/skills/tao-dev/references/glossary.md)。本项目自身使用 Git，因此维护提交约定使用 Git 专有术语；面向使用方的流程采用 VCS。

<!-- tao:section usage -->
## 四、使用规则

通用用词规则见随包术语表。tao-dev 自身以简体中文维护权威正文，代码标识、文件名、机器字段与提交日志使用英文；这不限制使用方语言。理由见 {need}`ADR_20260914_WX7BFBRXENPN4CT7`，模板和诊断遵循 [本地化规程](../plugins/tao-dev/skills/tao-dev/references/localization.md)。
