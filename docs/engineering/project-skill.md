# 项目级纯技能架构

<!-- tao:section overview -->
## 概述

技能负责文档语义与知识生命周期，持久计划与任务负责项目进度，工具负责 ID、文档、查询和出版。执行编排由智能体自行管理，实际成果必须回写项目材料。规格见 {need}`DOC_20261108_ZT37NM8REHBYC520`。

<!-- tao:section architecture -->
## 架构

源码位于 `skills/tao-dev/`。完整技能由使用者复制到客户端的项目级技能发现目录，或交给通用 skills 工具；tao 不管理分发生命周期，不记录安装归属。辅助 CLI 提供 `doctor`、`id`、`show`、`new`、`status`、`retire`、`verify`、`docs` 及必要项目设置；文档创建、修订和语义审查由智能体按文档契约完成，不提供通用开发动作或阶段编排。

<!-- tao:section contracts -->
## 接口与数据契约

核心文档使用 v0.1 的结构、ID 和引用形式，校验必要语义章节，允许章节重排。计划通常内联任务，也可显式关联一份任务附件，两者只选其一。任务描述可验证成果，客户端任务仅表示临时执行步骤。`status` 返回计划位置、任务计数与未完成项，不复制验证正文、不返回流程建议、不认定交付完成；验证和审查依据读取计划原文。`new` 只生成计划骨架；ID 支持批量生成。

`status` 和 `show` 不因无关草稿诊断阻断读取；返回 `partial` 和 `documents_valid=false`。所选任务集合缺失、关联错误或损坏时返回 `unavailable`、`task_set_valid=false`、`task_counts=null`，不把部分可解析任务冒充全部任务。ID 分配扫描已有文档与退役记录中的标识符即可，不要求先通过整本文档校验才能写作。

<!-- tao:section invariants -->
## 不变量

不修改用户级配置；项目辅助命令的输出不能写到授权项目之外。复制前确认目标为项目内新目录，不覆盖用户改动；手工复制不提供所有权检测或事务保证。`status` 不写入文件、不运行检查。所有任务勾选只表示记录的成果进度，不代表已验证、已审查或已交付。跨会话、协作或需要跟踪的工作维护持久计划，小改动复用适用文档，不强制同时编写规格、设计和计划。智能体核对事实后回写计划；完成计划作为变更记录，当前事实维护在规格、设计、ADR 和指南。普通证据与审查材料不自动建档或提交。保留有长期价值的已有文档与稳定 ID；删除过时契约时同步引用和导航，不为不兼容接口保留兼容层。

<!-- tao:section errors -->
## 错误与恢复

文档有歧义时如实列出候选，不按文件修改时间猜测。新会话从计划、唯一任务集和实际文件核对事实，不依赖临时摘要或客户端状态；损坏计划给出路径和诊断，不覆盖用户文件。手工更新前保存本地改动，完整替换旧副本，避免叠加复制遗留废弃文件；移除只针对确认过的技能目录，不删除项目文档。第三方安装工具的保护与恢复由该工具定义；只在显式调用时运行检查。

<!-- tao:section verification -->
## 验证

文档审查核对要求覆盖和所有权边界，代码审查关注路径越界、无状态查询、错误的完成判断和客户端发现。结构规范、模板、解析器、引用与文档导航保持一致。集中执行定向与完整回归、临时项目中的真实 CLI 冒烟检查及文档构建；结果只在计划中保留当前摘要。
