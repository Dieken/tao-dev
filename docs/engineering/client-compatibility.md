# 客户端兼容性与验收边界

<!-- tao:section scope -->
## 分层判定

记录 Claude Code、Codex、Cursor、Kiro 的项目发现目录，路径和官方来源见 [接入指南](../user/clients.md)。skill 使用 name、description 与相对资源路径，由客户端原生发现机制加载；tao 不维护客户端安装适配。

<!-- tao:section steps -->
## 验收层次

1. 静态资源：完整 skill、相对链接与平台文件路径正确。
2. 文件部署：完整复制到项目目录、复制后 CLI 可运行，移除副本后项目文档与外部环境不变。
3. 客户端发现：实际版本在目标项目发现 skill，项目外不发现。
4. 行为：模型实际读取文档与计划资源、维护语义契约和唯一项目进度、遵守授权与只读边界，正确调用可用辅助工具并如实回写结果。客户端临时任务不替代持久成果任务，不要求通用开发阶段编排。

任何一层通过不替代下一层。官方文档只支持入口选择，不证明本机运行成功。执行时记录实际客户端版本、操作系统、调用与观察范围；没有真实运行结果保持未知。

## 试验约束

复用已有 CLI 和认证，不修改个人配置、不安装全局 skill、不替用户登录。所有文件与清理限定隔离项目，需验证项目外缺席。客户端缺失、认证不可用或无法证明隔离就报告阻断，不能转用全局入口。通用工具安装与手工复制分别记录实际范围，不将官方文档或第三方工具的支持列表视为本项目验证。
