# 客户端兼容性与验收边界

<!-- tao:section scope -->
## 分层判定

支持四种项目安装适配：Claude Code、Codex、Cursor、Kiro，路径和官方来源见 [接入指南](../user/clients.md)。skill 使用 name、description 与相对资源路径，由客户端原生 skill 发现机制加载。

<!-- tao:section steps -->
## 验收层次

1. 静态资源：完整 skill、相对链接与平台文件路径正确。
2. 文件部署：项目内安装升级卸载、归属保护及隔离成立。
3. 客户端发现：实际版本在目标项目发现 skill，项目外不发现。
4. 行为：模型实际读取相关资源、遵守授权与只读边界、正确调用可用辅助工具并如实报告结果。

任何一层通过不替代下一层。官方文档只支持入口选择，不证明本机运行成功。执行时记录实际客户端版本、操作系统、调用与观察范围；没有真实运行结果保持未知。

## 试验约束

复用已有 CLI 和认证，不修改个人配置、不安装全局 skill、不替用户登录。所有文件与清理限定隔离项目，需验证项目外缺席。客户端缺失、认证不可用或无法证明隔离就报告阻断，不能转用全局入口。未列出的客户端不声明安装管理支持。
