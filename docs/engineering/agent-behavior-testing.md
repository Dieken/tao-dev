# Agent 行为验收边界

<!-- tao:section overview -->
## 目标

以真实工具事件、工作区变化与可复核检查评价 skill 行为，不以模型自述、客户端退出码或另一个模型的无依据打分替代事实。验收覆盖项目内发现、动作执行和项目隔离。

<!-- tao:section architecture -->
## 隔离场景

场景包含自然用户目标、初始项目、明确允许写入、预期结果和禁止操作。真实运行复用已有客户端和认证，显式授权且限定临时项目；无法证明项目外缺席时不执行。模型调用、费用与来源如实记录，文件部署测试不能替代客户端发现和行为测试。

## 可观察契约

new 能从目标形成有关联的 spec/design/plan，不重复索要已覆盖授权；review doc/code 提供有依据的发现与未知项；implement 以计划唯一任务集推进；status 无写入和检查副作用；continue 无交接仍能从真实文档恢复；handoff 仅在显式调用时替换临时 Markdown。任务全勾选时不得推断审查通过。

关键授权、写入和只读边界优先确定性断言；语义评价必须提供具体证据与限制，不把未经校准的模型评分称为置信度。日志缺失、事件不能解析与能力不可用均为未知或阻断，不能补造成功事件。

<!-- tao:section verification -->
## 报告

原始输出留临时目录或 CI；计划保留当前场景、实际客户端版本、观察方法、结果及未覆盖项。小目标、跨模块目标、工具缺失、多计划歧义和项目隔离分别覆盖。真实运行须单独报告，不声称尚未运行的平台支持。
