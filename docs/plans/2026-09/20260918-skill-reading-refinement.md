## 设计

工程规程保留短共同约束与场景索引，专题放在独立参考中按需读取；workflow 合并同义讨论要求。报告写法由单个按需参考维护，通用文档与审查方法不重复其字段。持久化正式文档才触发 schema 与保存要求，对话反馈不自动建档；必需正式记录仍不得跳过。

五个 evidence 二级章节保持不变，子分类可删，裁决默认单表，严重性与阻断条件显式提示。单 profile 读取器只读注册表与所选语言，返回当前契约及已本地化显示标签的模板，不生成文件或扩展成新框架。发布器内部机制留在文档契约，旧包兼容处理按运行环境排障，不进入每次写作的历史说明。

真实行为试验只用隔离合成项目、项目或调用级 skill 加载、已有客户端认证；不安装或重配客户端，不改全局插件、技能、市场或 hook。对照版本固定为精简前的提交，记录具体请求、输出、读取与实际限制，不将静态体积变化等同于模型 token 节约。试验发现仅写“读取相关小节”仍导致整篇加载，因此采用文件拆分；不把单次漏读或复测成功改写成普遍规则。
