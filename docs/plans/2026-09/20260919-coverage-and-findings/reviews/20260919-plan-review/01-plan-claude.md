## 发现与限制

<!-- tao:field limits -->
**限制:** 只审查了计划文档本身，未审查计划将要修改的六份参考页，也未验证规则改动落地后 agent 是否真的执行这些核对。单审查者、跨模型但同供应商，不能排除供应商层面的共性偏差。「未发现问题的部分」是该审查者的覆盖范围陈述，不代表穷尽。

### 缺陷

#### D1：收尾任务遗漏对告警修正任务的真实依赖

- **严重性与阻断条件:** 中；非阻断。按依赖图顺序执行时成立。
- **定位:** 受检计划的任务章节，收尾任务 {need}`TASK_20260919_YK293K37D4TNXZ59`。
- **约束:** 该计划验证章节自述「维护回归在全部编辑完成后运行一次，不在每个任务后重跑」，且其收尾断言要求全仓受管理文档诊断由 1 条降为 0 条；[正文写法](../../../../../../plugins/tao-dev/skills/tao-dev/references/document-content.md) 规定依赖图由字段生成，是执行顺序的唯一权威依据。
- **触发条件:** 告警修正任务 {need}`TASK_20260919_5ZRZJAXBWEDHFAT2` 的 `depends_on` 为空且无任务依赖它，收尾任务的 `depends_on` 不含它。
- **证据或待证假设:** 直接读取两项任务的关系字段确认图结构；已复核确认。
- **后果:** 收尾的一次性回归与 0 诊断断言可能在告警修正之前执行，导致断言不成立，或需要额外再跑一次回归，两者都违反计划自述的批处理原则。
- **最小改动或验证:** 将告警修正任务加入收尾任务的 `depends_on`。

#### D2：必读底座基线字节数与实测不符

- **严重性与阻断条件:** 低到中；非阻断。
- **定位:** 同一计划的目标与边界章节及验证章节，「6,537 字节」处。
- **约束:** 该计划验证章节自述该数值「须人工测量并记录」。
- **触发条件:** 执行者按计划字面以 6,537 字节为基线核对时成立。
- **证据或待证假设:** 已复核确认。实测 [SKILL.md](../../../../../../plugins/tao-dev/skills/tao-dev/SKILL.md) 1,843 字节加 [流程操作](../../../../../../plugins/tao-dev/skills/tao-dev/references/workflow.md) 4,737 字节，合计 6,580 字节；两份文件自提交 `2469362` 起未改动；在产出「6,537」说法的提交上以 `git show` 取出同样得到 6,580。该数字在写下时即为错误，被后续批次继承。
- **后果:** 按错误基线核对会得出与实测矛盾的结论。本批不修改这两份文件，增量为 0，因此「未增大」的结论本身仍成立。
- **最小改动或验证:** 改为实测的 6,580 字节，并记录上一批数值有误及其复核依据。

### 风险

**R1：覆盖对照机制在结构上看不见设计侧决定。** 严重性中偏高，非阻断。该计划新增的覆盖对照按需求建表，而格式注册表中 `UC` 的 `required_options` 含 `verifies` 且只能指向 `REQ`，`ADR` 的 `required_options` 仅有 `id` 与 `status`、无任何强制关系，任务的 `relates_types` 只允许 `REQ` 与 `CHG`。因此用例经 `verifies` 已归属需求，而设计决定可以合法地不关联任何需求，纯需求覆盖表无法枚举到它。触发条件是某次设计中出现不挂靠需求的决定。后果是用户原始观察中「设计侧未被覆盖」的失效模式原样保留，只是对象由需求换成设计决定。这是结构推断，未在真实事项上复现，属待证假设。最小改动或验证为把覆盖对照的左列由「需求」扩展为「本次范围内的需求加本次新增或修改的设计决定」。

### 非阻断建议

**S1：清除既有告警的决定未回应此前记录的保留结论。** 严重性低。同一条告警此前至少在五个批次文档中出现，其中 [操作与审查证据](../../../20260918-operation-review-evidence.md) 明确判定其「表示尚未生成的文件名，不是可导航对象，人工核对后保留」。计划改为修正但未提及这是重议。按 [独立审查](../../../../../../plugins/tao-dev/skills/tao-dev/references/review.md) 的强度表，项目或用户有明确要求时按该要求执行，因此重议本身正当，这只是可追溯性记录不完整。建议在计划中写明此次修订了既有的保留记录及其触发条件。

### 已接受限制

计划声明本批改动为 agent 行为规则，确定性检查无法证明改动后 agent 真会执行这些核对，规则实际效果须在后续真实事项中观察。审查认可该限制陈述，未要求本批补行为试验。
